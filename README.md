### ⚛️ 2. QuantumVault — Quantum-Safe Password Manager

**Tech Stack:** Java 21 · Spring Boot 3.5 · Spring Security · JWT · H2 · AES-256-GCM · Kyber-768 · BCrypt

Developed a secure password management REST API exploring layered encryption and post-quantum cryptography.

- 🔒 Used AES-256-GCM to encrypt vault entries.
- 🔑 Integrated Kyber-768 key encapsulation mechanisms into the security design.
- 🛡️ Implemented JWT authentication, BCrypt password hashing, and role-based access control.
- 📦 Developed CRUD operations for password vault management.
- 📊 Added password strength scoring based on entropy and estimated cracking time.

**Key Highlight:** Explores defense against future quantum threats while applying modern application security principles.

🔗 **Repository:** [View Project](https://github.com/VSMANOJKUMAR/Quantum-Vault)

### 🩺 4. Diabetic Retinopathy Detection System

**Tech Stack:** Python · PyTorch · ResNet-152 · Tkinter · FPDF2 · Transfer Learning

Developed an offline image classification application for grading diabetic retinopathy from retinal fundus images.

- 🧠 Fine-tuned ResNet-152 using transfer learning and a custom classification head.
- 📊 Classified retinal images into five severity levels.
- 🖥️ Built a multithreaded Tkinter interface with live image previews.
- 📑 Generated clinical PDF reports using FPDF2.
- 🎯 Achieved **96.7% validation accuracy** in the reported evaluation.

**Key Highlight:** Built an end-to-end image-to-report workflow designed to run offline.
